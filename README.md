# Controls
- Player 1 movement : wasd
- Player 1 interaction : E
- Player 2 movement : arrows
- Player 2 interaction : Enter
- Pause : Escape

# Setup from source
```sh
git clone https://github.com/vii-abdullatif/Pairadox
cd Pairadox # And open folder with Godot 4.7
```
